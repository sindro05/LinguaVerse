# 🌍 LinguaVerse

LinguaVerse is a language-learning platform combining:

- 📚 Structured language courses
- 🧠 Grammar
- 🗣️ Speaking practice
- 🎯 Exercises
- 🎮 Gamification
- 📊 Learning progress
- 🌎 Social learning
- 🎬 Educational videos
- 🤖 AI-powered learning

## V1

The first version focuses on:

- Authentication
- Languages
- CEFR levels
- Courses
- Modules
- Lessons
- Vocabulary
- Grammar
- Exercises
- Progress
- XP
- Streaks
- Dashboard
